# Approved Vendor List
## Overview

The Innodisk camera modules, camera adapter boards, and embedded peripheral modules that have been validated on our platform. Pick a category to see the supported models. For flashing or booting the device first, see [Starting Guides](../starting-guides/README.md).

| Category | Covers |
| --- | --- |
| [GMSL Camera](./gmsl-camera/README.md) | GMSL2 camera modules for long-distance installation. |
| [MIPI Camera](./mipi-camera/README.md) | MIPI CSI-2 camera modules. |
| [Camera Adapter Boards](./camera-adapter-boards/README.md) | Boards that connect GMSL and MIPI cameras to the platform. |
| [Embedded Peripheral Modules](./embedded-peripheral/README.md) | LAN, serial, CAN Bus, and Wi-Fi / Bluetooth modules. |
