# Camera Adapter Boards

Camera adapter boards connect [GMSL](../gmsl-camera/README.md) and [MIPI CSI-2](../mipi-camera/README.md) cameras to the platform. For driver, usage, and test report information, see [iQ-Cam__manifest](https://github.com/InnoIPA/iQ-Cam__manifest).

## Supported Camera Adapter Boards

| Model | Interface | Key Specs | Deserializer |
| --- | --- | --- | --- |
| [EB120-1S8F](https://www.innodisk.com/en/products/camera/capture-card/eb120-1s8f) (Coming soon) | GMSL2 | SAMTEC 120-pin x1 to GMSL2 mini FAKRA x2, up to 8 camera ports | Maxim MAX96724 x2 |
| [EB022-2M4F](https://www.innodisk.com/en/products/camera/capture-card/eb022-2m4f) | GMSL2 | MIPI CSI-2 22-pin x2 to GMSL2 IPEX FAKRA Z x4 | Maxim MAX96724 |
| [EB120-1S4M](https://www.innodisk.com/en/products/camera/capture-card/eb120-1s4m) | MIPI CSI-2 | SAMTEC 120-pin x1 to MIPI CSI-2 22-pin x4 | N/A |
